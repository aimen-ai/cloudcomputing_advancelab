# cloudcomputing_advancelab
lab work of the course Cloud Computing 

Lab title	 : GitHub for Cloud-Based Development and Deployment

Lab Objectives
•	Understand repositories, commits, branches, remotes and version history.
•	Upload and manage project files in a cloud-hosted GitHub repository.
•	Use Git commands to clone, stage, commit, pull and push changes.
•	Collaborate using branches, Issues and Pull Requests.
•	Publish a static website using GitHub Pages.
•	Create a basic GitHub Actions workflow and inspect its result.
•	Follow safe repository practices and avoid exposing secrets.
